# B87 手冊功能對照

依使用者提供的 B87 操作手冊整理。這份對照區分軟體控制與實體快捷鍵，不能用來推導未確認的 USB 指令。手冊沒有保證同名鍵盤使用相同主控或韌體。

| 手冊項目 | Rust 版入口 | 目前範圍 |
|---|---|---|
| USB 有線連線 | 裝置狀態、重新讀取 | 檢查受支援 HID 介面；背面開關仍需切至有線位置 |
| 藍牙三裝置 | 手冊功能 → 連線 | Fn＋Q／W／E 長按配對、短按切換；軟體無配對指令 |
| 2.4G 配對 | 手冊功能 → 連線 | G 模式、Fn＋P 配對；軟體無接收器配對指令 |
| 電量顯示 | 裝置狀態、系統匣 | 顯示 Windows 藍牙回報及時間；鍵盤 Fn＋Enter 仍在無線模式使用 |
| 旋鈕音量與靜音 | 手冊功能、按鍵測試 | 保留鍵盤原生旋鈕功能；未確認旋鈕重新指派方式 |
| 背光亮度、速度 | 燈效 | 軟體可調，也保留 Fn＋方向鍵 |
| 動態／單色背光 | 燈效 | 模式 1–17、色票、混色、自訂 RGB；實體 Fn＋Scroll／Home 仍可使用 |
| 側邊光顏色 | 手冊功能 → 燈光 | 手冊為 Fn＋Insert；沒有已確認 USB 指令，軟體不能直接切色 |
| 主背光／指示燈開關 | 燈效 | 主背光模式與 payload[26] 分別控制；欄位與手冊的整體關燈行為不完全等價 |
| 自訂背光錄製 | 手冊功能 → 燈光 | Fn＋1、Fn＋Print、逐鍵操作後儲存；沒有軟體寫入機內錄製資料的指令 |
| 逐鍵 RGB | 自訂燈光 | 電腦端即時串流、126 RGB 槽、四種逐鍵行為；和機內錄製不同，離開程式後不持續運算 |
| Win Lock | 手冊功能 → 系統 | Fn＋Win；軟體尚無已確認的鎖定狀態／切換指令 |
| Windows／Mac 模式 | 手冊功能 → 系統 | Fn＋A／S；不假設軟體改鍵等同切換韌體系統模式 |
| 恢復出廠 | 手冊功能 → 系統、設定檔 | 先備份，再長按 Fn＋空白鍵；軟體不送未確認的重置指令 |
| Windows／Mac 多媒體鍵 | 按鍵重設、手冊功能 | 保留手冊快捷鍵；可指派已支援的媒體動作，新增音量提高／降低及停止播放 |

## 手冊以外的功能

四層草稿與復原、巨集庫、配置方案、音樂律動、備份、讀回核對與失敗還原屬於軟體功能。這些功能已移至 Rust；實機已驗證的範圍與仍待確認項目見 [hardware-validation.md](hardware-validation.md)。

## 尚需實機證據的工作

- 擷取原廠軟體操作或取得可信協定資料，才能研究側燈切色、Win Lock、系統模式及機內背光儲存的 USB 控制。手冊只描述 Fn 操作，不能證明存在對應的 USB 指令。
- 現有改鍵維持舊版已使用的 104 槽／416 bytes；即時 RGB 為 126 槽／378 bytes。舊協定筆記記錄原廠曾傳送 126 槽改鍵，但新版沒有逕自擴大寫入長度。
- 防抖、Tap 時間單位、側邊指示燈方向與各種休眠時間，需要逐項實機驗證。介面送出的值不代表已確認實際手感或顯示效果。
- 巨集與色票沒有已確認的讀回路徑；設定檔不能宣稱備份這些未知硬體內容。
