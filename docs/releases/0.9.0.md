# iLovbee Studio 0.9.0

側欄改用不透明底色，修正原生視窗深色背景上看不清文字的問題。介面可跟隨 Windows，也可在左下固定選擇淺色或深色；縮放後仍保留八個功能名稱。

- 補回 C# 主程式的外部 `live.ini` 同步與依 DPI 產生的系統匣圖示。
- 保留舊版按鍵、巨集、方案、備份、逐鍵 RGB、音樂律動與系統匣功能；新增完整功能對照與回歸測試。
- 示範模式改用模擬頻譜，不開啟真實 WASAPI 音訊。
- 加入 HTTP 本文停止傳輸後的逾時恢復、內容安全政策與原生視窗導覽限制。
- 發佈建置加入單元／整合、瀏覽器、資安、壓力及鎖定相依弱點門檻，失敗時不更新封裝目錄。

本機通過 39 項 Rust 測試、62 項瀏覽器檢查及 32 併發、兩輪共 8,000 次請求的壓測。Windows x64 MSVC／GNU 的 266 個可達相依套件查詢沒有已知弱點命中；測試報告隨下載包附於 `validation`。

本版使用隔離示範裝置測試，未使用鏡頭、實體鍵盤壓測或真實音訊。機內背光錄製仍須按實體鍵操作，圖樣尚不能由軟體直接寫入或備份。完整範圍見 `docs/csharp-parity.md` 與 `docs/release-validation.md`。

下載 Windows x64 ZIP、解壓縮後執行 `iLovbeeStudio.exe`；不需要 .NET，Tauri 視窗需要 Windows WebView2 Runtime。首次使用先建立鍵盤設定備份。
