# iLovbee Studio 0.9.0

## 繁體中文

- 修正側欄文字看不清楚的問題，縮放後仍顯示功能名稱。
- 提供跟隨 Windows、淺色與深色主題。
- 補回外部設定同步，改善系統匣圖示的縮放顯示。

下載 Windows x64 ZIP，解壓縮後執行 `iLovbeeStudio.exe`。需要 Windows 10／11 x64 與 WebView2 Runtime。

本專案僅供個人自用，依手上的 BY Tech B87 驗證。其他鍵盤或不同版本的 B87 可能不適用。

## English (US)

- Improved sidebar readability and kept navigation labels visible when resizing.
- Added system, light, and dark themes.
- Restored external configuration sync and improved tray icon scaling.

Download and extract the Windows x64 ZIP, then run `iLovbeeStudio.exe`. Requires Windows 10/11 x64 and WebView2 Runtime.

Built for personal use with a specific BY Tech B87. Other keyboards, including different B87 variants, may be incompatible.
