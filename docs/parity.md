# 與原廠 iLovbee Keyboard 的功能對照

更新：2026-10-19。「已實測」＝在實體 B87 上驗證（讀回比對，或使用者按鍵確認）。

| 原廠功能 | 本程式 | 狀態 |
|---|---|---|
| 按鍵重設（預設層、FN1、FN2） | 按鍵重設頁，草稿、復原、批次套用、讀回核對、失敗還原 | 已實測 |
| Tap 層（第 4 層） | 編輯層下拉的「Tap 層」，寫入層 3 | 已實測（讀回） |
| 3 組配置方案 | 本機方案庫（最多 20 組，四層）：另存、套用、刪除 | 已實測（讀回）；缺重新命名、匯出入 |
| 巨集管理器 | 錄製、手動編輯、延遲、最多 8 個巨集、寫入鍵盤、指派到按鍵 | 已實測（按鍵輸出確認，含修飾鍵與延遲）；缺匯入匯出原廠巨集檔 |
| 燈效模式 1–17、亮度、速度、顏色、混色 | 燈效頁，全部欄位來自實機解碼 | 模式切換、亮度、顏色、休眠已實測；預覽動畫為模擬，部分模式與實機仍有差異 |
| 休眠時間 | 燈效頁 | 僅 10 分鐘值與原廠核對過 |
| 自訂燈效（模式 18，逐鍵 RGB） | 未實作 | 原廠由電腦每 0.78 秒串流 126 鍵 × RGB（指令 08）；需常駐程式 |
| 音樂模式 | 未實作 | 電腦端錄音後即時串流，同上 |
| 設定頁（防抖、Tap 時間等） | 未實作 | 原廠設定欄位位於燈效 payload 的 Cfg[3]（防抖）、Cfg[22]（Tap）；範圍與單位未解碼 |
| 韌體更新 | 刻意不做 | 風險高，且不應以任何非原廠映像更新 |
| 電量顯示、按鍵測試、備份還原、系匣小工具 | 有 | 原廠沒有的額外功能 |

## 刪除原廠軟體前的建議

- 仍需要自訂燈效或音樂模式時，保留原廠軟體。目前只要不使用這兩項，日常功能已可完全取代。
- 原廠安裝檔（`work/vendor/iLovbee-Keyboard-Setup-V1.0-20241220.exe`）請另外保存；原廠不再更新，之後重裝只能靠它。
- 原廠軟體儲存時會用自己畫面上的狀態覆蓋鍵盤的燈效，解除安裝前後請先建立完整備份（設定檔頁）。
- 鍵盤上的巨集資料在解除安裝原廠軟體後仍會保留，不會被清除。
