# iLovbee Studio

**BY Tech B87（理論上也包含同套件方案鍵盤）的輕量設定工具，取代已停止更新的原廠 iLovbee Keyboard。**

iLovbee Studio 是 Windows 上設定 BY Tech B87 機械鍵盤的工具，包含按鍵重設、巨集、燈效、逐鍵 RGB 與音樂律動。

- 整個程式只有一個約 3 MB 的 Native AOT 執行檔，常駐在系統匣。
- 設定介面是程式在本機提供的網頁，可以用選用的 Tauri 視窗開啟（Mica 背景、與介面融合的標題列）。

原廠軟體已不再更新。本專案在實機上監看鍵盤通訊，解出協定後重新實作原廠的功能，另外也加了幾項原廠沒有的功能。

## 功能

### 按鍵與巨集

- **按鍵重設**：預設、FN1、FN2、Tap 四層都能改。
  - 可指定一般按鍵、F13–F24、媒體鍵、Win+D 和自訂組合鍵。
  - 修改先存成草稿，可以復原／重做，再一次套用。
- **巨集**：可以錄製，也可以手動編輯（含延遲與修飾鍵）。最多 8 個寫入鍵盤，每個都能指派給任何按鍵；巨集庫可以匯入匯出。
- **配置方案**：四層鍵位存在本機，一鍵套用，也能重新命名、匯入匯出。

### 燈效

- **內建模式 1–17**：有動態示意預覽，可調亮度、速度、色票和混色。
- **自訂 RGB**：每個模式色票的第一格都能指定任意顏色，跟原廠的色輪是同一個設定。
- **側邊指示燈**：勾選就能開關，不必按 Fn+Backspace。
- **鍵盤設定**：防抖（辦公／遊戲）、Tap 開關與時間、無線休眠時間。

### 自訂燈光（即時串流）

- **逐鍵 RGB**：每顆鍵都能設定任意顏色。
- **逐鍵行為**：每顆鍵可以各自恆亮、閃爍、呼吸或彩虹循環，速度可調。
- 一鍵彩虹或依排漸層，配置庫最多存 20 組。
- **音樂律動**：12 種樣式，跟著 Windows 正在播放的聲音跳動。
  - 配色可以用彩虹混色，或自訂 1–6 色漸層。
  - 漸層可以沿高度、頻率、時間或強度變化。

### 其他

- **備份**：預設每次寫入前先備份，寫入後讀回核對，失敗就還原。
  - 自動備份可以關閉；失敗還原不依賴備份檔。
  - 自動與手動備份分開計算，預設各保留 5 份（可調整，上限 100），超過的舊備份會刪除。
  - 也能完整匯出、還原設定檔。
- 按鍵測試、USB 連線狀態、藍牙電量與低電量通知。
- 系統匣選單可快速切換燈光，也能設定開機自動啟動。

## 支援硬體

| 裝置 | USB ID | 韌體 release |
|---|---|---|
| BY Tech B87 | `258A:0199` | `2010` |

理論上，本程式只適用於這把鍵盤，或採用同一套主控晶片與韌體方案（同套件方案）、通訊協定相同的鍵盤。所有協定都是在一把 B87 上解碼和測試的，其他型號都沒有驗證過。

- 其他同樣叫「B87」的鍵盤，韌體可能不同，所以**不支援**。
- 只要 USB ID 或 release 跟上表不完全相同，程式就會拒絕寫入，同套件方案的鍵盤也一樣。
- 想在同套件方案的其他鍵盤上試用，得自己修改原始碼裡的這項檢查，而且務必先完整備份。

## 開始使用

### 需求

- Windows 10／11 x64
- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- Visual Studio Build Tools（含 C++ 工作負載，Native AOT 連結時需要）
- 選用：Rust 工具鏈（要建置 Tauri 視窗才需要）

### 建置與安裝

```powershell
git clone https://github.com/HsuanC0921/ilovbee-studio.git
cd ilovbee-studio
./build.ps1               # 先跑測試，再發佈到 dist/
./scripts/install.ps1     # 安裝到目前的 Windows 帳號
```

想用 Tauri 視窗的話，先建置它，`build.ps1` 會自動放進 dist：

```powershell
cd ui
cargo build --release
```

沒有 Tauri 視窗時，設定介面會改用 Edge 應用程式視窗開啟。連 Edge 都沒有的話，就用預設瀏覽器開啟。

安裝程式會做這些事：

- 把程式放到 `%LOCALAPPDATA%\Programs\iLovbee Studio`
- 建立開始功能表捷徑
- 登錄到 Windows「已安裝的應用程式」

安裝不需要系統管理員權限，也不必先裝原廠軟體。

### 解除安裝

從 Windows 設定 →「應用程式」解除安裝，或執行安裝資料夾裡的 `uninstall.ps1`。設定和備份會留在 `%LOCALAPPDATA%\iLovbeeStudio`，不會被刪除。

## 使用方式

1. **先結束原廠 iLovbee 程式。** 兩個程式同時寫入會互相覆蓋，所以原廠驅動還在執行時，本程式會拒絕寫入。
2. 用 USB 連接鍵盤，並切到有線模式。
3. 開啟 **iLovbee Studio**，按「**重新讀取**」讀取鍵盤。

關掉設定視窗後，程式仍會常駐在系統匣（約 20 MB）。要完全結束，請從系統匣選單按「**結束小工具**」。系統匣選單也能切換音樂律動和自訂燈光，以及開關「**開機自動啟動**」。

自訂燈光和音樂律動是由常駐程式一格一格送給鍵盤的，所以只在程式執行時有效。停止後，鍵盤會回到原本的燈效模式。

## 安全設計

寫入硬體的流程刻意做得保守：

- **備份 → 寫入 → 讀回核對 → 不符就還原。** 還原用的是記憶體中的寫入前狀態，所以就算關閉自動備份也有效。開啟備份時，鍵盤沒辦法讀回的資料（巨集、色票表）也會先備份，色票表另外存一份在本機。
- 只允許已知、長度正確的指令。程式絕不送出韌體更新、ISP 或 DFU 指令。
- FN 鍵不能被改掉。

本機網頁介面的防護：

- 只監聽 `127.0.0.1` 的隨機埠。
- 需要啟動時產生的一次性權杖（HttpOnly、SameSite=Strict Cookie）。
- 會檢查 `Host` 與 `Origin`，其他網站無法呼叫。

## 開發

```powershell
dotnet run --project tests/Checks.csproj -c Release
```

測試涵蓋：

- 封包標頭與長度限制
- 設定檔驗證
- 按鍵與巨集編碼（對照原廠實機封包）
- 色票表與備份設定
- 逐鍵行為與音樂律動畫面

`build.ps1` 每次發佈前都會先跑測試。

## 已知限制

- **側燈顏色無法更改。** 還沒找到對應的指令，原廠軟體也沒有這個設定。
- 燈效預覽是軟體模擬，少數模式跟實機效果略有差異。
- 電量顯示的是 Windows 最近一次透過藍牙回報的數值，所以至少要配對過一次。
- 沒有修改藍牙韌體，不宣稱能改善無線穩定性。
