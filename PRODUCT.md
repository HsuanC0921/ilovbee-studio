# iLovbee Studio

Platform: native Windows desktop, x64. Stack: C#, .NET 10 NativeAOT single executable (Win32 tray, local HTTP server on 127.0.0.1) with a plain HTML/CSS/JS settings UI shown in an Edge app window.

One Traditional Chinese Windows user needs a professional replacement for the abandoned B87 controller. Hardware is BY Tech B87 USB 258A:0199 release 2010; Bluetooth name B87 5.0. Do not treat same-name WB32 variants as compatible.

The calculator key is assigned Win+D (Show Desktop / restore windows); F13 remains available. Physical knob is at Pause position. Its mapping is not assumed from the OEM diagram; its diagram action opens key testing.

Remapping: searchable actions, custom chords, three-layer drafts, undo/redo, selected-key revert, draft export/resume, change review, complete backups and verified transactional apply. Retain FN. Other pages: lighting, device/battery status, key testing and profiles. No firmware research or unfinished engineering commentary in product UI.

Battery: Windows Bluetooth device battery property is validated on actual hardware. Show its percent and report time, never reinterpret uncalibrated USB bytes as percent. BLE standard Battery Service is a fallback. The tray host updates once per minute and warns for recent low reports.

Custom integrated title bar; native caption controls, taskbar behavior and Fluent focus affordances. Neutral workbench with blue selection and pale blue pending edits. Minimize explanatory prose; status and controls should communicate the workflow.

Verification: treat code tests, native layout checks and actual device reads/writes as distinct evidence. User requests avoiding repeated Computer Use; native RenderTargetBitmap and programmatic layout checks cover two desktop widths. Research remains in docs/firmware.md. No telemetry or automatic uploads.
